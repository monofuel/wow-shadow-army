- [x] figure out how to run the **traverse** eval locally **faster** (not the
      accelerated leveling league) so we don’t burn **45 wall minutes** per test
  - **Question:** can local `--league=traverse` / `make traverse` finish a useful
    test loop without waiting out the full 45m episode?
  - **Stock answer (2026-08-04):** **no first-class fast-traverse mode.**
    The traverse fixture hardcodes episode wall length as
    `max_ticks / tick_rate` = `27000 / 10` = **2700 s (45m)** from
    `infra/coworld_manifest_template.json` variant `kalimdor-south-to-north`.
    Local profile loads that via `game/local_league.py` with **no launcher flag**
    on `launch_nim_player` to cut duration or raise sim scale.
  - **How the 45m is enforced:** game server sleeps wall time
    `config.max_ticks / config.tick_rate` (`game/server.py`), independent of
    movement. `vmangos.simulation_time_scale` defaults to **1** on this profile.
  - **What exists today (partial, not “fast full eval”):**
    1. **Full traverse fixture (45m wall if left alone):** `make traverse` /
       `nim r tools/launch_nim_player.nim -- --league=traverse`.
    2. **Proof-of-life only (~2 in-world minutes):** `--league=traverse
       --proof-of-life`. Admission smoke (≥50 yd), **not** a desert/course eval.
    3. **Manual early stop:** kill the session when the test goal is met
       (e.g. V1 Gadgetzan ~2154 yd northing). Dashboard yards still work.
       Startup cost remains; you just don’t sit through the rest of the 45m.
  - **Levers that would actually make local evals shorter (not shipped as
    flags today — would need a small local hook):**
    1. **Lower local `max_ticks`** (e.g. 3000 → ~5 wall min episode end). Best
       for auto-stop after a short test window. Must only apply to **local**
       prepare, never change hosted tournament contract.
    2. **Raise local `simulation_time_scale` (2–10):** world/gameplay advances
       faster in wall time (Coworld VMaNGOS scale is real), so you reach a
       desert checkpoint sooner. Episode **wall sleep can still be 45m** unless
       you also cut `max_ticks` or kill the process when done.
    3. **Goal-based local stop** (northing ≥ N or proof receipt): stop launcher
       when V1 target hit — same idea as proof-of-life, scoped to desert yards.
  - **Bottom line:** today, faster local traverse testing = **short goals +
    early kill**, or **proof-of-life** for micro smoke. A real “fast traverse
    eval” needs a **local-only max_ticks and/or sim-scale override** on prepare
    (not in stock CLI yet).
