is three layers only — **`kb/`** / **`lua/` tools** / **LLM planner (later)**.

## Definition of done (migration)

Migration is **done** only when all of the following are true:

1. **No bot decide path through Python.** No seat is driven by
   `python -m brain.*` in normal ops.
2. **All named intents live under `lua/tools/`** with unit tests under
   `lua/tests/`. Policy behavior is not implemented in Nim except thin
   host glue (socket, frame project, intent→wire, audit).
3. **Standing `make` targets are Nim host + Lua only:**
   `escort`, `escort-army`, grind army, quest/imp tools, party accept/promote
   as needed. No `uv run … python -m brain.*` for bot play.
4. **`brain/` is gone or quarantined.** Prefer delete. If anything must
   linger for offline forensics, it is not imported by Makefile bot targets
   and is not part of `make test` default.
5. **`make test` does not require Python for bot correctness.** Lua + Nim
   unit tiers cover tools, intent map, host helpers. Optional offline
   scripts (e.g. quest data regen) may remain Python if monofuel keeps them
   as one-off tooling — they are not the bot.
6. **Live smoke:** 4-seat army on Nim host runs escort/grind/quest tools
   without starting any Python brain process.

Anything short of this is **not done**. Partial ports + checked boxes count
as failed migration.

## Architecture (non-negotiable)

```
upstream nim_control.v2 (+ fork execute_action)  ←→  Nim host (army_host)
                                    │
                                    ├─ install goals (leader/party) + watchdogs + audit  [goal mode]
                                    ├─ project observation → plain table (projectV2)     [--external]
                                    ├─ run lua/tools/<name>.decide(frame, args)          [--external]
                                    └─ map intent → typed BotAction → execute_action     [--external]

kb/*.md     bot memory for the LLM planner — RESERVED, empty, unbuilt
docs/*.md   everything written for humans/agents on this repo
lua/tools/  ALL policy and named intents — LIVE on the grind rail since
            2026-07-27 via the fork's execute_action frame
            (docs/nim-control-v2-external-select.md); escort still runs the
            upstream in-process policy pending its external live smoke
(later)     LLM planner picks tool names; does not emit raw wire actions
```

Rules (also in `AGENTS.md`):

- **NO PYTHON** for bots, policy, tools, brain loops, or tests of those layers.
- Prefer upstream goals/masks over home-grown FSMs.
- Do not grow `brain/`. Port or delete.
- Do not cheat (GM progress, DB pokes, seat collusion).

Nim is allowed for: socket framing, msgpack/json, projection, intent→wire,
audit log, promote helper, one-shot ops that are not “decide each frame.”
If a behavior can be a named intent, it goes in Lua.
